# Muestras

Coloca aqui los Excels de entrada de ejemplo (uno por cada formato/origen distinto que exista).

Se usan durante el desarrollo para:
- Revisar en que fila (1 o 2) y en que columna aparece cada variable.
- Definir el mapeo encabezado-origen -> variable-plantilla en `config/alias_encabezados.json`.
- Definir la regla final de nombre de hoja, con nombres de archivo reales.

Estos archivos son solo para desarrollo/pruebas; no se incluyen en el ejecutable final.
